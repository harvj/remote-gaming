# P1.3 frontend dependency audit

The baseline npm audit grouped advisories into seven affected packages. The production-only npm graph still contains some build dependencies because the Svelte plugin is installed for asset compilation. Reachability below reflects actual use.

The lockfile fixes all seven package groups within the existing dependency ranges. It selects Svelte 5.55.7, Vite 6.4.5, devalue 5.9.3, nanoid 3.3.18, Picomatch 2.3.2 and 4.0.4, PostCSS 8.5.23, and source-map-js 1.2.2. The Svelte patch also raises its minimum esrap version. The overall and production dependency audits returned zero findings after a clean install.

## devalue

Serialization and parsing edge cases require untrusted devalue input, special values, or evaluating generated source. Tracked through the Svelte package. Gameplay uses JSON and contains no direct devalue call.

- Moderate — devalue has prototype pollution in devalue.parse and devalue.unflatten. [GHSA-cfw5-2vxh-hr84](https://github.com/advisories/GHSA-cfw5-2vxh-hr84)
- High — Svelte devalue: DoS via sparse array deserialization. [GHSA-77vg-94rm-hx3p](https://github.com/advisories/GHSA-77vg-94rm-hx3p)
- Low — Sveltejs devalue's `devalue.parse` and `devalue.unflatten` emit objects with `__proto__` own properties. [GHSA-mwv9-gp5h-frr4](https://github.com/advisories/GHSA-mwv9-gp5h-frr4)
- Moderate — Svelte devalue: DoS via malformed input. [GHSA-9rgm-9g3h-6x36](https://github.com/advisories/GHSA-9rgm-9g3h-6x36)
- High — devalue: `stringify`/`uneval` serialize shared memory. [GHSA-j22f-vq7h-c4qm](https://github.com/advisories/GHSA-j22f-vq7h-c4qm)
- Moderate — devalue: Residual sparse-array CPU amplification in uneval. [GHSA-hx4r-w6wj-j8fg](https://github.com/advisories/GHSA-hx4r-w6wj-j8fg)
- High — devalue: Repeated primitive strings cause quadratic expansion in uneval. [GHSA-mcm9-63f2-9j32](https://github.com/advisories/GHSA-mcm9-63f2-9j32)
- Low — devalue: Sparse arrays emitted by uneval cause eager allocation when evaluated. [GHSA-wf3x-273g-mvxv](https://github.com/advisories/GHSA-wf3x-273g-mvxv)
- Moderate — devalue: Malformed null-prototype object keys bypass __proto__ rejection via property-key coercion. [GHSA-4q55-j62x-fr9h](https://github.com/advisories/GHSA-4q55-j62x-fr9h)
- High — devalue: Custom ArrayBuffer revivers can bypass typed-array allocation validation. [GHSA-r9w8-h9r3-54w4](https://github.com/advisories/GHSA-r9w8-h9r3-54w4)

## nanoid

Invalid or attacker-controlled size is needed for these loop or range faults. Transitive via PostCSS in the build. Remote Gaming credential generation uses server-side SecureRandom.

- High — nanoid: non-secure generators can loop indefinitely with negative size. [GHSA-28wg-ghj8-5hjv](https://github.com/advisories/GHSA-28wg-ghj8-5hjv)
- High — nanoid: custom generators can loop indefinitely when size is zero. [GHSA-2v37-7h3g-55p8](https://github.com/advisories/GHSA-2v37-7h3g-55p8)

## picomatch

Attacker-controlled glob expressions can alter matching or exhaust CPU. Build and development matching in Vite and fast-glob. No gameplay endpoint passes user input to a glob.

- Moderate — Picomatch: Method Injection in POSIX Character Classes causes incorrect Glob Matching. [GHSA-3v7f-55p6-f55p](https://github.com/advisories/GHSA-3v7f-55p6-f55p)
- High — Picomatch has a ReDoS vulnerability via extglob quantifiers. [GHSA-c2c7-rcm5-vvqj](https://github.com/advisories/GHSA-c2c7-rcm5-vvqj)

## postcss

Affected paths need attacker-controlled CSS or source maps. PostCSS runs at build time on repository CSS. Rails serves compiled assets.

- High — PostCSS: Arbitrary file read and information disclosure via attacker-controlled sourceMappingURL in CSS comments. [GHSA-6g55-p6wh-862q](https://github.com/advisories/GHSA-6g55-p6wh-862q)
- Moderate — PostCSS: incomplete fix of GHSA-6g55-p6wh-862q — attacker-controlled sourceMappingURL reads arbitrary .map files when `from` is unset. [GHSA-fxqj-rqcc-2cmp](https://github.com/advisories/GHSA-fxqj-rqcc-2cmp)
- High — PostCSS: Path Traversal in Previous Source Map Auto-Loading (sourceMappingURL) leads to Arbitrary .map File Disclosure. [GHSA-r28c-9q8g-f849](https://github.com/advisories/GHSA-r28c-9q8g-f849)

The separate Ruby audit reported 220 findings in 27 packages. The report matched the pre-P1.3 lockfile, including Rails, Rack and WebSocket dependencies. Treat Ruby remediation as a separate release gate before changing the deployed authentication stack. Brakeman reported zero warnings.

## v0.3.0 reconciliation

A fresh Ruby audit confirmed the 220-finding baseline. Compatible patches to the Rails 8.1 series and the locked Devise, Puma, Rack, Rack Session, WebSocket, HTML-processing and supporting gems reduced the audit to 28 findings. The latest scan lists Addressable, Mail, Net::IMAP, MCP, Rack Proxy, RubyZip, and SQLite3. These span development and test tooling, mail libraries, and transitive runtime dependencies. In particular, Passphrase still pins the SQLite3 1.x series for its local word lists, while the advisory fixes require 2.x. Assess the remaining findings and record the approved staging risk decision before enabling Auth with real accounts. The scan continues to report findings.
